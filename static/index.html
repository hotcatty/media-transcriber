读取登录状态

将读取你选的浏览器里已经有的登录状态，用于解析登录后才能看的视频。读的不是账号密码，也不会发到网上。

点「点击读取」后，程序只在这台电脑上查看你选的浏览器里有没有该网站的登录 Cookie，拷一份给解析用。不是账号密码，也不会发到网上。没登录、无痕或没保存登录会读不到。

无法获取登录 Cookie？

可能是这台电脑上的浏览器还未登录该网站，因此无法获取登录 Cookie。

下载并打开本机服务

第一次需要在这台电脑上打开一次本机服务。系统会提示无法验证，这是正常的。按下面做就能打开，不要点「移到废纸篓」。

第一次需要在这台电脑上打开一次本机服务。下载解压后打开即可，一般不用过安全验证。

目前测试包支持 Mac 和 Windows。请用电脑打开这一页后再下载。

  1. 点下面的「下载本机服务」，浏览器会下一个压缩包。
  2. 打开「下载」文件夹，双击压缩包解压。如果已有旧的「转录小工具」，先移到废纸篓，再打开这次解压出来的。
  3. 如果弹出「未打开」：点左边灰色的「完成」，不要点蓝色的「移到废纸篓」。
  4. 打开左上角苹果菜单 → 系统设置 → 隐私与安全性，拉到最下面的「安全性」。
  5. 看到已阻止「转录小工具」，点「仍要打开」，再确认一次「打开」。
  6. 回到这一页，粘贴链接，点「转录为逐字稿」。
  1. 点下面的「下载本机服务」，浏览器会下一个压缩包。
  2. 打开「下载」文件夹，解压压缩包，双击里面的 start.bat。
  3. 第一次准备大约几分钟。看到已经准备好后，回到这一页。
  4. 粘贴链接，点「转录为逐字稿」。

也可以按住 Control 点「转录小工具」，选「打开」。如果还是同一句提示，就用上面的系统设置。准备好后会提示「已经准备好」，回到这一页即可，不必反复打开这个程序。如果系统说「应用程序无法打开」，也先回到这一页试试。打开失败时会弹出说明页，点「下载说明.txt」，把这个文件发给我。

如果弹出「Windows 已保护你的电脑」，点「更多信息」，再点「仍要运行」。没有这句提示就不用管。
